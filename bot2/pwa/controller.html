API keys & Gemini Live voice

Keys entered here stay in this page's memory and are not saved to local storage. They are sent over HTTPS to your authenticated signaling backend; for a shared/public deployment, prefer configuring keys as Render environment variables. Gemini Live uses a short-lived token rather than exposing the long-lived Gemini key to its WebSocket. The controller can send that one-use token to the authenticated robot phone to start its own AI voice session.

Patrol settings

Safety: Patrol is limited to short low-speed pulses and stops if the camera detector sees an object, loses video/model readiness, or reaches the time limit. This is not reliable collision avoidance. Test only in a clear, enclosed test area with wheels lifted first; never leave it unattended.
