CONNECTION NOTES

First-time setup

  1. Open this app in a supported Android Chrome version and install it from the browser menu if desired.
  2. Connect the ESP32-S3 using a data-capable USB-C cable and an OTG-capable phone.
  3. Tap Connect USB-C and grant USB/serial permission.
  4. Start camera and load the model. First model load needs internet; subsequent availability depends on browser caching.

Android USB serial browser support varies by Chrome version, phone, and ESP32 USB interface. If the port cannot be opened, use a native Android USB-serial bridge or a browser/device combination that supports Web Serial/WebUSB.
